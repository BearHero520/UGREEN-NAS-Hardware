# Almighty 分析方法归档

本目录只保留本项目自编的方法源码和结构化结论，不包含原厂镜像、提取出的原厂程序、模块、固件源码、反汇编原文或第三方工具。

`method-manifest.json` 保存历史源码提交 `a18af13` 的分析断点及本轮新增的验证方法，按原阶段目录区分；`firmware-research-summary.json` 区分固件证据、静态推断和未知。后续修复不自动继承这些历史验证结果。

方法文件以 `.py.txt` 作为可审查文本归档，内容及 SHA-256 保持原样。它们原先位于清单中的本地 work 路径，依赖原始固件、固定目录布局及未入库的分析工具；不是可直接执行的通用工具。部分脚本会生成或覆盖分析输出。复做时先复制到新的 work 阶段目录，核对输入 SHA-256，显式调整输入/输出路径并安装所需工具，禁止在已冻结证据目录直接运行。文件中的本地固件路径是历史取证位置，不是下载地址或必须存在的路径。

可直接使用的构建/测试复现工具另见 `tools/testing/`、`tools/toolchains/` 和 `docs/BUILD_REPRODUCIBILITY.zh-CN.md`。自动打包状态仍以 `models/compatibility.json` 为准。
