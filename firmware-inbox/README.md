# 固件临时投放区

这个目录用于把待逆向的系统包临时交给 Codex，不作为固件仓库。

## 使用方法

1. 把原始镜像、升级包或驱动包放进 `input/`。
2. 告诉 Codex 文件名、目标机型和重点能力；也可以直接使用 `docs/FIRMWARE_REVERSE_PLAYBOOK.zh-CN.md` 末尾的提问模板。
3. Codex 将原包保持只读，把临时拆包结果放到 `work/<包名或机型>/`。
4. 有长期价值的结论会整理到 `docs/`，证据足够后再修改模型或硬件实现。

`input/` 和 `work/` 的实际内容已被 `.gitignore` 忽略，避免把大型镜像、原厂二进制和临时提取物提交到 Git。目录内文件不会自动清理。
